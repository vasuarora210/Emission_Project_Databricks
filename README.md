# Emission Data Analysis using Databricks

## 📌 Overview
Analyzed global CO2 emissions data using Databricks SQL to identify trends, patterns, and insights across countries, states, and population.

## 🛠️ Tools & Technologies
- Databricks
- SQL

## 📊 Key Analysis
- Emission per person
- Emission by country
- Emission by state
- CO2 emissions trends

## 🔍 Key Insights
- Identified top emitting countries and regions
- Observed correlation between population and emissions
- Highlighted regions with highest per capita emissions

## 📈 Outcome
Built dashboards to help visualize emission patterns and support data-driven environmental insights.

## 📁 Files
- SQL notebooks (.ipynb)
- Dashboard (.lvdash)
